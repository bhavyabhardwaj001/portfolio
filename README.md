# Bhavya Bhardwaj Portfolio

A personal portfolio website showcasing my work as a full-stack developer with a focus on AI and practical systems.

## Description

This is a responsive, modern portfolio built with HTML, CSS, and JavaScript. It features a dark theme with an animated starfield background, smooth scrolling navigation, and sections highlighting projects, skills, experience, and contact information.

## Features

- Responsive design that works on desktop and mobile devices
- Animated starfield background using HTML5 Canvas
- Smooth scroll navigation with active section highlighting
- Project showcase with images, descriptions, tech stacks, and live demo links
- Skills section organized by categories (Languages, Web & Tech, Tools)
- Experience section detailing internship at IIT Bombay
- Contact section with email and social links
- Accessibility features including ARIA labels and semantic HTML

## Technologies Used

- **HTML5**: Semantic structure and content
- **CSS3**: Custom properties, flexbox/grid layouts, animations, and responsive design
- **JavaScript (ES6+)**: Interactive features, canvas animations, scroll observers, and navigation

## Setup and Installation

1. Clone or download the repository to your local machine.
2. Open `index.html` directly in a web browser to view the portfolio.
3. For development, use a local server (e.g., VS Code's Live Server extension) to avoid CORS issues with any external resources.

No build process or dependencies are required as this is a static website.

## Usage

Navigate through the sections using the fixed header navigation or scroll naturally. The portfolio is optimized for viewing on various screen sizes.

## Projects Featured

1. **Mental Health Assistant (MindEase)**: A full-stack AI-powered chatbot for emotional support, featuring NLP, sentiment analysis, and mood tracking.
2. **Student Activity Platform**: A centralized platform for event management and student engagement, built with React, Node.js, and MongoDB.
3. **eSim Automated Tool Manager**: A Python CLI tool for automating eSim tool installations on Linux systems.
